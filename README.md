# مكتب أفق للحج والعمرة

موقع عربي ثابت لمكتب أفق للحج والعمرة. يحتوي المستودع على الصفحتين `index.html` و`4.html`، والصور، وملف التلبية الصوتي.

## تشغيل نسخة محلية

من جذر المشروع شغّل خادم ملفات ثابتة، مثل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

> قد تمنع بعض المتصفحات تشغيل الصوت تلقائيًا قبل أول تفاعل من الزائر. يبدأ الصوت تدريجيًا وبمستوى محدود عند السماح بذلك.

صورة واجهة البداية عمل فني مولّد بمساعدة الذكاء الاصطناعي اعتمادًا على صورة مرجعية مرخّصة؛ وهي مشهد فني وليست توثيقًا فوتوغرافيًا لواقعة بعينها. بقية صور Pexels وروابط تراخيص المواد موضحة في `README-AR.txt`.
